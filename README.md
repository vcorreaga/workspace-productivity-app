# Workspace Productivity App

Workspace Productivity App es una aplicación web enfocada en la organización de tareas y productividad personal/profesional, inspirada en herramientas modernas de trabajo colaborativo como Monday, Notion y otros espacios de gestión visual.

Más allá de una simple lista de tareas, este proyecto busca transmitir una experiencia de enfoque, claridad y acompañamiento visual para las actividades del día a día. La idea nace desde la necesidad de crear un espacio más humano e intuitivo para priorizar responsabilidades, visualizar avances y mantener control sobre tareas importantes dentro de un entorno moderno y organizado.

La intención principal del proyecto no es únicamente registrar tareas, sino crear una experiencia que ayude al usuario a sostener objetivos, identificar retrasos, comprender por qué ciertas metas no se cumplen y mantener mayor constancia en sus procesos personales o laborales.

También surge desde una visión enfocada en productividad colaborativa, organización visual y control de procesos, tomando como inspiración plataformas workspace modernas, pero buscando integrar una experiencia más cercana, visual y orientada al seguimiento real del cumplimiento de actividades.

---

# Funcionalidades

- Inicio de sesión con persistencia en LocalStorage
- Rutas protegidas
- Dashboard interactivo
- Crear tareas
- Completar tareas
- Eliminar tareas
- Gestión de prioridades
- Fechas de vencimiento
- Indicadores de tareas atrasadas
- Filtros dinámicos
- Métricas visuales de productividad
- Barra de progreso dinámica
- Alertas visuales con SweetAlert2
- Diseño responsive

---

# Inspiración del proyecto

La interfaz y experiencia visual están inspiradas en plataformas de productividad modernas tipo workspace, buscando crear una experiencia más organizada, limpia y visualmente amigable para el usuario.

El proyecto también busca transmitir una visión más intuitiva sobre el cumplimiento de tareas, el seguimiento de procesos y la importancia de mantener continuidad en actividades pendientes, especialmente aquellas que suelen quedar atrasadas dentro de la rutina diaria.

# Instalación y ejecución

Clonar repositorio:

```bash
git clone https://github.com/vcorreaga/workspace-productivity-app.git
```

Instalar dependencias:

```bash
npm install
```

Ejecutar proyecto:

```bash
npm run dev
```
